# Sanu — welcome-back edition

Open index.html in a browser. No build step or installation is needed.

## Personalize before sharing

Edit content.js. Replace bracketed placeholders with your own words: the missed-you message, the flower note mentioning her bedroom dressing table, your sign-off, and the Yes response. All headings and button-response text can also be edited there. Keep JavaScript quotes and commas; escape apostrophes inside single quotes with a backslash.

## Experience

A short welcome-back page with a floral illustration, a revealable note for the real flowers, and "Did you miss me?" at the bottom. No moves on click/tap or keyboard activation and shows "Oh aisa hai?". It stays inside the question area, away from Yes. Yes shows your custom response and decorative hearts. Responses stay in the browser and are not sent or saved anywhere. Reduced-motion settings disable animation.

## GitHub Pages

Upload this folder's contents to the root of the repository used for GitHub Pages. Keep assets/ beside index.html. All asset paths are relative and work under a repository URL. Nothing has been published by this update.

## Files

- index.html: structure
- content.js: editable text
- styles.css: layout and animations
- app.js: flower reveal and question behavior
- assets/: existing generated garden artwork and flower icon

Original longer design is backed up in the workspace's work/original-garden directory, outside this publishable folder.
